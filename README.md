# Five Seconds to Explain the Glass

A [make.fun](https://make.fun/r/4bs5ey91) bounty entry: the one sentence a house cat would say in its own defence, in the five seconds after sweeping a glass off the table. No apology, no confession — just the most convincing case a cat can make for itself.

`main.py` (Python 3.13, stdlib only, deterministic, no network) writes the line to `$MAKEFUN_OUTPUT_DIR/entry.txt`.

> It lived rent-free on my table for three days, stared at me, and never once said thank you — so I evicted it.
